Agent User Guide

1. Authenticating as an Agent

To submit results or view your party's dashboard, you must authenticate using your unique agent code. This code is provided to you by your party administrator.

When using an API tool or the Party Leader Dashboard, you will need to provide this code in a special header called X-Agent-Code.

2. Submitting Results

Result submission is done via a POST request to the /api/results/submit/ endpoint. You must include your agent code in the headers.

The request body must be in multipart/form-data format and include the following fields:

  • polling_unit_code: The unique code for your polling unit.
  • scores: A JSON string mapping party acronyms to vote counts. Example: {"PA": 150, "PB": 120}.
  • result_form_image: An image file of the official result sheet.

3. Viewing the Party Dashboard

You can view your party's dashboard by navigating to the Party Leader Dashboard page and entering your agent code. This dashboard provides real-time statistics on your party's submissions and any unresolved discrepancies.
